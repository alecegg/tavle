# Page

## Orientation

Markdown page rendering for standalone docs. `assemble` builds the page fragment and the static export, `render` and `fences` turn fenced `ui` blocks into HTML, `include` and `select` plan included parts, and `anchors` and `toc` give blocks their ids and the table of contents. `page_check` and `page_quality` report errors and warnings. `edit` rewrites one block, `actions` lists its menu, and `template` holds the HTML shell shared by the served page and the export.
