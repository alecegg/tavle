# UI components

## Orientation

tavle owns the component vocabulary and the page: statement parser, component specs, prepared props, views, CSS, theme maths and the standalone shell (`blocks`, `blocks_render`, `theme`), plus Markdown page rendering, includes, checks, the comments store, the page server, export and chrome assets (`page`, `comments`, `serve`, `listings`). It imports no Varde code.

Tests live in `tests/ui` (components) and `tests/page` (pages).
